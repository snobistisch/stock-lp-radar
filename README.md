# Stock LP Radar

A production-ready Next.js dashboard for researching Stock Token liquidity on Robinhood Chain. It combines meme-base demand from StonksOnChain, asset verification through Rialto and RWA pool metrics from Revert Finance.

The interface uses an original terminal design that blends VFAT-style data density with Bloomberg-inspired market conventions: monospaced typography, function-key navigation, black panels, orange system status, green returns, cyan liquidity and compact tables. No brand assets or exact screens are copied.

> Research tool, not financial advice. According to Robinhood documentation, Stock Tokens are debt instruments and do not grant shareholder rights in the underlying equity.

## Strategy

The scanner targets Stock Token pools paired with **USDG** and **WETH**. The objective is to capture fee income generated by meme activity without directly holding pure memecoins. USDG is the more defensive quote asset; WETH introduces additional volatility and impermanent-loss risk.

The smart score combines:

- usable TVL and active liquidity;
- fees relative to TVL;
- 30-day APR, capped to reduce the impact of outliers;
- pool age and data quality;
- an explicit penalty for medium and high risk.

The score is a ranking heuristic, not a return forecast.

## Stack

- Next.js 15 App Router + TypeScript
- Server Component for initial data
- Static data provider and client refresh, compatible with GitHub Pages
- Tailwind CSS and shadcn/ui-compatible components
- Recharts
- Dark mode by default, responsive and Vercel-ready

## Run locally

```bash
git clone https://github.com/snobistisch/stock-lp-radar.git
cd stock-lp-radar
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Quality checks:

```bash
npm run typecheck
npm run lint
npm run build
```

`npm run check` runs all three checks. The same validation runs in GitHub Actions on pushes and pull requests.

## Deploy on Vercel

1. Import the GitHub repository into Vercel.
2. Select the Next.js framework preset.
3. Copy any required variables from `.env.example`.
4. Deploy; no custom build configuration is required.

## GitHub Pages

Every push to `main` builds and publishes the static export to:

[https://snobistisch.github.io/stock-lp-radar/](https://snobistisch.github.io/stock-lp-radar/)

The workflow sets `NEXT_PUBLIC_BASE_PATH=/stock-lp-radar`, runs typecheck and lint, builds `out/` and deploys the artifact through GitHub Pages. It can also be started manually through **Actions → Deploy GitHub Pages → Run workflow**.

## Data snapshot

The bundled version uses a research measurement from **September 3, 2026 at 17:04 UTC**. The refresh button updates the local session timestamp but does not change the underlying measurements while `DATA_SOURCE=static`. See [DATA.md](./DATA.md) for source definitions, validation rules and the live-data migration path.
